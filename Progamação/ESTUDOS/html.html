Estrutura basica do Arquivo HTML

Estrutura e Sintaxe.

HTML, Hyper Text Markup Language, responsável por estruturar o conteúdo de uma página web, como links, textos, marcações, imagens, etc. Composto por elementos representados por <tags>.

Acima mostra uma estrutura básica de um documento HTML, essas tags presentes na imagens estão presentes em todos os documentos HTML em sua origem.

<!DOCTYPE html>
Declaração do tipo de documento, informa ao navegador que o documento é um arquivo HTML5.
<html>
Elemento raiz do documento HTML, envolve todo o conteúdo da página.
<head>
Contém informações sobre o documento, como título, metadados e links para arquivos externos.
<body>
Contém o conteúdo visível da página, como texto, imagens, links e outros elementos.

Cada tag tem uma função específica e pode conter atributos que modificam seu comportamento. Mas será um tema tratado mais a frente.

Resumindo: Todo documento HTML tera uma estrutura básica com as tags <!DOCTYPE html>, <html>, <head> e <body>.

Sabendo a estrutura geral de maneira basica, agora é necessario enxergar como funciona a SINTAXEdo html

Acima mostra a sintaxe do HTML, onde cada elemento é representado por uma tag de abertura e uma tag de fechamento, com o conteúdo entre elas. As tags podem ter atributos que fornecem informações adicionais sobre o elemento.



HTML Semântico

HTML Semantico.

HTML semântico é uma abordagem de desenvolvimento web que utiliza tags HTML com significado específico para descrever o conteúdo da página. Essas tags fornecem informações sobre a estrutura e o propósito do conteúdo, tornando-o mais compreensível para os navegadores, mecanismos de busca e leitores de tela.

São todas as tags como <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>, etc.

Elas possuem um certo grau de hierarquia e organização na pagina para que haja uma melhor comprensão do sistema ao ler o código.

HTML semantico serve para ordernar corretamente o conteúdo da página. Asim melhorando a maneira que o sistema web le o codigo.

Exemplo: O elemento <header> é usado para definir o cabeçalho da página, enquanto o elemento <footer> é usado para definir o rodapé. O elemento <main> é usado para definir o conteúdo principal da página, enquanto o elemento <aside> é usado para definir conteúdo complementar.

Metadados

Essas tags são: <!DOCTYPE >, <html>, <head>, <title>, <meta>, <body>, <link>, <base>, <style>.

Tag Descrição
<!DOCTYPE> Informa o brownser que o documento é um arquivo HTML5.
<html> Elemento raiz do documento HTML, envolve todo o conteúdo da página
<head> Contém informações sobre o documento, como título, metadados e links para arquivos externos.
<title> Define o título da página, exibido na aba do navegador.

<style> Permite incluir estilos CSS diretamente no documento HTML.
